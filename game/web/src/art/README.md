# Иллюстрации

Все картинки игры по умолчанию — встроенные SVG (`kit.tsx`, `monsters.tsx`, `cards.tsx`).
Чтобы заменить любую из них своей, положите файл в **`src/art/custom/`** с именем из таблицы ниже.
Подходят `.png`, `.jpg`, `.webp`, `.avif`, `.svg`, `.gif`. Расширение любое, регистр имени не важен.

После добавления файла перезапустите `npm run dev` (или пересоберите `npm run build`). Код менять не нужно.

**Формат:** горизонтальный кадр **4:3** (например, 800×600). Картинка обрезается по центру (`object-fit: cover`),
поэтому главное держите в центре, а по краям оставляйте поля примерно по 10 %. На клетках поля показывается уменьшенная копия.
