## Расхождения, найденные аудитом, и исправления

| # | Расхождение | Исправление | Регрессионный тест |
|---|---|---|---|
| AUDIT-1 | Помощник не получал награду, если игрок побеждал монстра шестёркой (только при победе по мощи) | Награда за Подмогу при любом захвате | `AUDIT-1 regression` |
| AUDIT-2 | Жетон Дани при полных ячейках получателя сгорал, а жетон награды заменял мелкий — два разных правила для одного действия | Одно правило `receiveToken` | `AUDIT-2 regression` |
| AUDIT-3 | Досрочное окончание в движке считало сначала мощь, а правила — Земли | Порядок «Земли → мощь → жетоны» | `AUDIT-3 regression` |
| AUDIT-4 | `rules/resolved/v014.json` не содержал двух полей, добавленных в движок позже (оба выключены) | Файл перегенерирован; тест идентичности web ↔ симулятор | `web ruleset file is identical…` |

После исправлений баланс перепроверен: скор 100.0, те же открытые проблемы.
