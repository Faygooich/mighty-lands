# Игра по сети (v1.0.3)

Комната с кодом из четырёх букв, как в Jackbox, но **у каждого своё устройство и своё поле**: на телефоне видно всю партию и свою руку, чужие руки скрыты.

Правила не изменились: v1.0.3 = правила **v029**, та же механика, что в v1.0.1 и v1.0.2. Новое — только сетевая игра.

---

## Как играть

1. Хозяин открывает сайт → **«Игра по сети»** → **«Создать комнату»**. На экране появляется код, например `ДAWK` → `DAWK`.
2. Остальные открывают **тот же сайт** → «Игра по сети» → **«Войти по коду»**. Или переходят по ссылке «Копировать ссылку» — код подставится сам.
3. В лобби: любой может переименоваться и переключиться между «за столом» и «только смотрю»; хозяин сажает ботов на свободные места, перемешивает места и жмёт **«Начать партию»**.
4. За столом каждый видит поле, соперников (только число карт) и свою руку. Ход делает тот, чья очередь; карты-ответы в чужой ход приходят тому, кто может их сыграть.

Мест — до 7 (как в офлайне), зрителей — сколько угодно. После партии хозяин может вернуть всех в лобби кнопкой **«Ещё партию»**.

### Если кто-то отвалился

- Страница перезагружена, телефон уснул, Wi-Fi моргнул — **место остаётся за игроком**: он возвращается по тому же коду (а по ссылке — автоматически) и продолжает. Партия его ждёт.
- Если ждать надоело, хозяин в меню партии («Меню» → список комнаты) передаёт место боту: **«Отдать боту»**. Когда игрок вернётся, место снова станет его.
- Вкладка хозяина в P2P-режиме — это и есть комната. Закрыл случайно — открывает сайт снова и жмёт **«Вернуть мою комнату ABCD»**: партия восстановится ход в ход, остальные переподключатся сами.

## Как это устроено

**Комната авторитетна.** Она держит единственный экземпляр движка (`game/core`) через тот же `Controller`, что и офлайн-игра. Игроки не считают правила у себя — они присылают только **номер выбранного варианта**, а получают готовое состояние. Значит: расхождений между устройствами не бывает, мухлевать нечем (из чужого кода можно выслать только свой же допустимый выбор), а боты играют в комнате — одинаково для всех.

```
game/net/protocol.ts   сообщения и типы (PROTOCOL = 1), коды комнат, токены
game/net/room.ts       комната: лобби, места, зрители, партия, боты, снимок для восстановления
game/net/view.ts       что видит участник: чужие руки и колоды скрыты
game/net/client.ts     участник: тот же интерфейс TableCtl, что у локальной игры, + переподключение
game/net/transport.ts  Link — двусторонний канал строк; loopback для хозяина в своей же вкладке
game/net/server.ts     свой сервер: те же комнаты в Node + раздача сборки (WebSocket)
game/web/src/net/      браузер: транспорт PeerJS, транспорт WebSocket, сессии, лобби, экраны
```

Комната ничего не знает про браузер: она работает и во вкладке хозяина (P2P), и в Node (свой сервер) — код один и тот же.

### Что скрыто

| Видно всем | Скрыто |
|---|---|
| Поле, Земли, владельцы, Артефакты на Землях | Руки соперников (видно только число карт) |
| Жетоны, МОЩЬ, число Земель | Порядок колод (видно только их размер) |
| Журнал партии, сыгранные и сброшенные карты | Какая карта пришла сопернику (событие «взял карту») |
| Кто сейчас думает и над чем (вид решения) | Варианты чужого решения (они выдали бы карты в руке) |

Когда партия закончилась, руки раскрываются всем — как за столом.

### Защита от нечестного хода

Каждый выбор помечен номером момента партии: комната принимает его, только если ход действительно ваш, вариант существует и с тех пор ничего не изменилось. Чужой или устаревший выбор игнорируется, а клиенту присылается актуальное состояние.

### Трафик

Ход — около 6 КБ, полная пересинхронизация после переподключения — 10–25 КБ (журнал обрезается до последних 250 строк). За партию на семерых набегает порядка мегабайта.

## Два режима связи

### P2P (по умолчанию)

Устройства соединяются напрямую по WebRTC. Публичный сервер PeerJS нужен только чтобы найти друг друга по коду (и как ретранслятор TURN для строгих NAT и мобильных сетей). Комната живёт во вкладке хозяина.

- Плюс: не нужен свой сервер, сайт можно положить на любой статический хостинг.
- Минус: вкладку хозяина нельзя закрывать (после перезагрузки комнату можно вернуть), и хозяину лучше не давать устройству уснуть — фоновая вкладка притормаживает ботов.

Свой сигнальный сервер вместо публичного (необязательно):

```bash
npx peer --port 9000 --path /mz          # пакет peer
# и сборка:
VITE_PEER_HOST=peer.example.com VITE_PEER_PORT=443 VITE_PEER_PATH=/mz npm --prefix game/web run build
```

### Свой сервер комнат

Комнаты живут в Node-процессе, все участники (включая хозяина) — обычные клиенты по WebSocket. Тот же сервер раздаёт и саму игру.

```bash
VITE_ROOM_SERVER=same npm --prefix game/web run build   # «сервер там же, где сайт»
npm run server                                          # PORT=8080, ROOM_IDLE_MS, MAX_ROOMS
```

- `POST /api/rooms {token}` → `{code}` · `GET /api/health` · `WS /ws/<КОД>`
- Пустая комната удаляется через 30 минут; `MAX_ROOMS` ограничивает их число.
- Плюс: хозяин может закрыть вкладку, партия не пропадёт; ничего не зависит от чужого сигнального сервера.
- Годится и для игры по домашней сети: запустите сервер на ПК и заходите с телефонов по `http://<ip-компьютера>:8080`.

Переключить режим можно и без пересборки — параметром в адресе: `?server=https://rooms.example.com`, `?server=same`, `?server=off` (только P2P).

## Где разместить

- **Любой статический хостинг** (GitHub Pages, Netlify, Cloudflare Pages): `npm --prefix game/web run build` и выложить `game/web/dist`. Работает P2P-режим, свой сервер не нужен. Сайт обязан открываться по **https** — иначе браузеры не дадут WebRTC.
- **Один процесс на VPS/Render/Fly**: `npm run server` (раздаёт сборку и держит комнаты). Нужен `VITE_ROOM_SERVER=same` на сборке или `?server=same` в адресе.

## Проверки

```bash
npm test                     # включая game/tests/net.test.ts (комната, скрытие, переподключение,
                             # восстановление) и server.test.ts (реальные HTTP + WebSocket)
npm run uicheck              # браузерная проверка: MODE=server|p2p, BASE=<url>, нужен Firefox или Chrome
```

`uicheck` поднимает две независимые сессии браузера (два «устройства»), создаёт комнату, входит по коду, сажает бота, начинает партию, делает ходы, проверяет, что чужих карт не видно, и перезагружает страницу гостя — тот должен вернуться на своё место.

## Известные ограничения

- Две вкладки одного браузера — это один и тот же игрок (место опознаётся по токену в `localStorage`): второе окно перехватывает место, первое получает «вы вошли с другого устройства». Для двух игроков на одной машине нужны разные браузеры или приватное окно.
- В P2P фоновая вкладка хозяина замедляет ботов (браузер душит таймеры). Держите её открытой на виду.
- Если сигнальный сервер недоступен, уже собравшиеся играют дальше, но новые игроки войти не смогут — в лобби хозяина об этом есть предупреждение.
- Комната не переживает потерю и вкладки хозяина, и сохранённого снимка (`localStorage`). Снимок хранится 12 часов.
