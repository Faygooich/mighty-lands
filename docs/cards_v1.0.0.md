Документ сгенерирован из тех же данных, что использует движок (`game/balancing/printCards.ts`). Жирный текст — правило, курсив — просто для смеха.

## Поле

**Врата** — *Врата. Здесь начинаются все великие приключения и большинство коротких.* Прошёл или встал — возьми жетон 100 (если есть свободная ячейка).

**Перекрёсток** — *Налево пойдёшь — монстра найдёшь. Направо пойдёшь — тоже. Тут везде монстры.* Ничего не происходит.
